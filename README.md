# feigntf2-cfg

My personal Team Fortress 2 configuration files.

## CFG

Based on [creeproot's config](https://drive.google.com/drive/folders/1p7pb_4FojhdX4qRBhPbhqFE3CYRRH8ra?usp=sharing) with personal adjustments.

## HUD

Personalized [HypnoHUD](https://github.com/Hypnotize/HypnoHUD)

## Settings

| Setting | Value |
|---|---|
| Sensitivity | 2.20 |

## Launch Options

```
-w 1680 -h 1050 -fullscreen -novid
```

## Installation

1. Clone the repo:
   ```bash
   git clone https://github.com/Feignetta/feigntf2-cfg.git
   ```
2. Copy the contents of `cfg/` to your TF2 cfg folder:
   ```
   ~/.steam/steam/steamapps/common/Team Fortress 2/tf/cfg/
   ```
